# sherpa-onnx (API de Java para texto a voz)

Copia sin cambios de los archivos de texto a voz de la API de Java de
[sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) v1.13.8 (licencia Apache 2.0, © Xiaomi Corporation).
Las librerías nativas para Windows (`sherpa-onnx-jni.dll`, `onnxruntime.dll`) las baja la compilación
de su release oficial. Es la última versión que trae el fonetizador de Piper (espeak-ng).
