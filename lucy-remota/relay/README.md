# Relé de Lucy Remota

Worker de Cloudflare (plan gratis) que junta a la PC y al teléfono cuando están en redes distintas.
Sólo reenvía bytes cifrados de punta a punta; ver «Relé» en `../protocol/PROTOCOLO.md`.

- Publicado en `https://lucy-remota-relay.devecchianderson12.workers.dev` (se publica solo desde `main`).
- Probarlo en local: `npm ci && npm run dev` y, en otra terminal, `npm test`.
